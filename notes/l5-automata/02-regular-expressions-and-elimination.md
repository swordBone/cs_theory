# L5 补充例题：正则表达式、ε-NFA 与状态消除

> 来源：`L5_0_1793243778225.pdf` 第 2-5 页，按 PDF 页序定位。下面重建这份材料中的两个例题：$`(01\cup0)^*`$ 的自动机构造，以及“1 的个数模 3 余 1”的状态消除。

正则表达式的定义、优先级、Thompson 构造和状态消除正确性见 [Week 5 笔记](../../理论计算机科学导引_Week5_整理笔记.md)。本篇补充新的转移表与消除过程；与原周记中的 $`(01\cup10)^*`$ 和偶数个 1 例题分别对应不同语言。

## 1. 从表达式构造 ε-NFA

顺序为：先搭 `0`、`1` → 连接为 `01` → 与另一支 `0` 取并 → 对整体加星号。不能误读成 $`01\cup0^*`$。

下面给出可直接检查的完整转移表。初态为 $`p_0`$，唯一接受态为 $`p_9`$，未列出的转移目标均为空集。

| 当前状态 | 读 `0` | 读 `1` | ε 转移 |
| --- | --- | --- | --- |
| $`p_0`$ | ∅ | ∅ | $`\{p_1,p_9\}`$ |
| $`p_1`$ | ∅ | ∅ | $`\{p_2,p_6\}`$ |
| $`p_2`$ | $`\{p_3\}`$ | ∅ | ∅ |
| $`p_3`$ | ∅ | ∅ | $`\{p_4\}`$ |
| $`p_4`$ | ∅ | $`\{p_5\}`$ | ∅ |
| $`p_5`$ | ∅ | ∅ | $`\{p_8\}`$ |
| $`p_6`$ | $`\{p_7\}`$ | ∅ | ∅ |
| $`p_7`$ | ∅ | ∅ | $`\{p_8\}`$ |
| $`p_8`$ | ∅ | ∅ | $`\{p_1,p_9\}`$ |
| $`p_9`$ | ∅ | ∅ | ∅ |

其中 $`p_2\to p_3\to p_4\to p_5`$ 是 `01` 分支，$`p_6\to p_7`$ 是 `0` 分支，$`p_8\to p_1`$ 负责再次选择一个块。

**检查答案：** 空串经 $`p_0\xrightarrow{\epsilon}p_9`$ 接受；`001` 可拆成 `0·01`；`010` 可拆成 `01·0`。`1`、`10`、`011` 都不能分解为若干个 `0` 或 `01`，因此拒绝。

## 2. 状态消除的检查要点

先增加没有入边的新初态，以及没有出边的唯一新接受态；保留旧状态上的转移。平行边取并，没有边的标签是 $`\varnothing`$，不是 $`\epsilon`$。

删除中间状态 k 时，对保留的状态 i、j（允许相同）更新：

```math
E'_{ij}=E_{ij}\cup E_{ik}(E_{kk})^*E_{kj}.
```

右边全部使用本轮删除前的标签。第一项保留原有通路，第二项允许进入 k、绕零次或多次自环、再离开 k。没有自环时 $`E_{kk}=\varnothing`$，但 $`(\varnothing)^*\equiv\epsilon`$，因此仍可以经过 k 一次。

## 3. 源例完整重建：1 的个数模 3 余 1

来源：第 4—5 页。原 DFA 初态是 $`q_1`$，唯一接受态是 $`q_3`$：

| 状态 | 读 `0` | 读 `1` | 计数含义 |
| --- | --- | --- | --- |
| $`q_1`$（初态） | $`q_1`$ | $`q_3`$ | 已读 `1` 的个数模 3 余 0 |
| $`q_3`$（接受态） | $`q_3`$ | $`q_2`$ | 已读 `1` 的个数模 3 余 1 |
| $`q_2`$ | $`q_2`$ | $`q_1`$ | 已读 `1` 的个数模 3 余 2 |

读 `0` 不改变计数；读 `1` 沿 $`q_1\to q_3\to q_2\to q_1`$ 循环。读完输入时只有余数为 1 才接受。

### 第一步：加首尾状态

增加 $`q_0\xrightarrow{\epsilon}q_1`$ 和 $`q_3\xrightarrow{\epsilon}q_f`$。三个原状态都保留 `0` 自环，$`q_3`$ 不再标为接受态。按手稿顺序依次删除 $`q_1,q_2,q_3`$。

### 第二步：删除 $`q_1`$

进入 $`q_1`$ 的外部边来自 $`q_0`$、$`q_2`$；离开 $`q_1`$ 的外部边到 $`q_3`$。因此补充两条边：

```math
E_{03}=\varnothing\cup\epsilon\,0^*1\equiv0^*1,
\qquad E_{23}=\varnothing\cup1\,0^*1\equiv10^*1.
```

其他保留的非空边为 $`E_{22}=0`$、$`E_{33}=0`$、$`E_{32}=1`$、$`E_{3f}=\epsilon`$。这张边表也说明，原来 $`q_2\to q_1\to q_3`$ 的路径已由 $`10^*1`$ 代替。

### 第三步：删除 $`q_2`$

剩余状态中只有 $`q_3`$ 进入 $`q_2`$，$`q_2`$ 也只离开到 $`q_3`$，因此更新 $`q_3`$ 的自环：

```math
E'_{33}=0\cup1\,0^*(10^*1)
       =0\cup10^*10^*1.
```

这一步 **必须与原有 `0` 自环取并**。若只写新回路 $`10^*10^*1`$，就漏掉在 $`q_3`$ 读零的可能性。

此时只剩 $`q_0\xrightarrow{0^*1}q_3`$、$`q_3`$ 上的自环 $`0\cup10^*10^*1`$，以及 $`q_3\xrightarrow{\epsilon}q_f`$。

### 第四步：删除 $`q_3`$

```math
R=0^*1(0\cup10^*10^*1)^*\epsilon
 \equiv 0^*1(10^*10^*1\cup0)^*.
```

这与手稿最终结果一致。最前面的 $`0^*1`$ 提供第一个 `1`；随后每个 `0` 块不增加 `1`，每个 $`10^*10^*1`$ 块恰好增加三个 `1`，所以生成的串一定满足个数模 3 余 1。

反过来，任意满足该计数条件的串，先把第一个 `1` 及其前导零匹配到 $`0^*1`$。余下的 `1` 可以每三个分组：组内相邻 `1` 之间的零由两个 $`0^*`$ 匹配，组与组之间和末尾的零由外层并分支 `0` 匹配。因此所有符合条件的串都被表达式覆盖。

| 输入 | `1` 的个数 | 结果 | 一种分解或原因 |
| --- | --- | --- | --- |
| $`\epsilon`$、`000` | 0 | 拒绝 | 缺少最前面必需的一个 `1` |
| `00100` | 1 | 接受 | `001 · 0 · 0` |
| `111` | 3 | 拒绝 | 模 3 余 0 |
| `1010101` | 4 | 接受 | `1 · 0 · 10101` |
| `1111111` | 7 | 接受 | `1 · 111 · 111` |

## 4. 对照原稿时的三处记号纠正

1. **第 3 页的并运算。** 应写 $`L(R_1\cup R_2)=L(R_1)\cup L(R_2)`$，左边不能误写成交运算。
2. **第 5 页的零步路径。** 若 $`L_{ij}^{(0)}`$ 指没有中间状态的路径所读字符串集合，则 $`L_{11}^{(0)}`$ 应含空串与直接 `0` 自环，即 $`\{\epsilon,0\}`$。这与 GNFA 图上只把实际自环标为 `0` 并不矛盾。
3. **第 5 页的表达式与语言。** $`R_{03}^{(1)}\equiv0^*1`$ 是表达式；对应语言写为 $`\{0^m1:m\ge0\}`$ 或 $`L(0^*1)`$，不能把 $`\{0^*1\}`$ 当成严谨的二进制字符串集合。

路径递推的完整定义、基础项与证明见 [Week 5 第 10 节](../../理论计算机科学导引_Week5_整理笔记.md)。其核心是限制**中间状态的编号范围**，而不是限制路径长度：

```math
R_{ij}^{(k)}=R_{ij}^{(k-1)}
\cup R_{ik}^{(k-1)}\bigl(R_{kk}^{(k-1)}\bigr)^*R_{kj}^{(k-1)}.
```

## 5. 自测与答案

1. $`\varnothing`$ 与 $`\epsilon`$ 表示同一语言吗？**不。前者语言为空，后者语言只含空串。**
2. $`(01\cup0)^*`$ 接受 `0100` 吗？**接受，可分解为 `01·0·0`。**
3. 星号构造只添加“从出口回入口”的 ε 边是否足够？**不够，还要确保零次重复时接受空串。**
4. 消除 k 时没有自环，是不是不能经过 k？**不是。自环标签取空表达式，其星号允许绕零次。**
5. 平行路径为什么取并而不是连接？**因为路径是二选一；连接表示先后都经过。**
6. 源例的 `0` 自环会改变 `1` 的计数余数吗？**不会，所以三处 `0` 自环都保留当前余数。**
7. 源例最终表达式接受 `11011` 吗？**接受，有四个 `1`，也可分解为 `1·1011`。**
8. $`R_{ii}^{(0)}`$ 中为什么有 ε？**因为从状态 i 到自身存在不走任何边的零步路径。**
9. $`R_{ij}^{(k)}`$ 是否只允许最多走 k 条边？**不是，限制的是内部状态的编号集合，不是路径长度。**
10. 两种消除顺序得到不同 RE，是否必有一个错误？**不一定。表达式形式可以不同，应比较其表示的语言。**
