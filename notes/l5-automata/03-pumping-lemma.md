# 正则语言的泵引理：量词、证明与反证方法

> 来源：`L5_0_1793243778225.pdf` **PDF 第 6 页**。该页包含泵引理、DFA 重复状态证明，以及 $`\{0^n1^n:n\ge0\}`$ 非正则的例题。本文补全量词与证明细节；第 5 节练习和第 6 节自测为整理时补充，并非原稿内容。
>
> 主线：有限状态必然重复 → 重复路径可以泵送 → 找到无法满足这种性质的字符串，反证语言非正则。

泵引理也称抽引引理。正则语言与自动机的基础见 [Week 4](../../理论计算机科学导引_Week4_整理笔记.md) 和 [Week 5](../../理论计算机科学导引_Week5_整理笔记.md)；进一步应用见[作业 2 第 6 题](../../作业2_解答.md)。

## 1. 引理说的是“存在一种可反复使用的拆分”

设 $`L\subseteq\Sigma^*`$ 是正则语言，则存在正整数 $`p`$，称为一个**泵长度**。对于每个满足 $`w\in L`$ 且 $`\lvert w\rvert\ge p`$ 的字符串，都存在拆分 $`w=xyz`$，使得：

1. $`\lvert y\rvert\ge1`$：被重复的部分非空。
2. $`\lvert xy\rvert\le p`$：被重复的部分位于前 $`p`$ 个符号之内。
3. 对每个整数 $`i\ge0`$，都有 $`xy^iz\in L`$。

这里 $`x,y,z\in\Sigma^*`$；$`x`$ 与 $`z`$ 可以为空，只有 $`y`$ 必须非空。特别地：

```math
xy^0z=xz,\qquad xy^1z=w,\qquad xy^2z=xyyz.
```

所以“泵”既允许增加重复，也允许删除一次 $`y`$。只检查 $`i=1`$ 没有证明作用，因为这时得到的就是原字符串。

### 把量词写完整

```math
\begin{aligned}
&\exists p\in\mathbb Z_{\ge1}\;\forall w\in L:\\
&\quad \lvert w\rvert\ge p\ \Longrightarrow\ \exists x,y,z\in\Sigma^*:\\
&\qquad w=xyz\ \land\ \lvert xy\rvert\le p\ \land\ \lvert y\rvert\ge1\\
&\qquad \land\ \bigl(\forall i\in\mathbb Z_{\ge0},\ xy^iz\in L\bigr).
\end{aligned}
```

按顺序理解：**先固定语言对应的 $`p`$，再考虑字符串 $`w`$，为这个 $`w`$ 找到一种拆分，最后让同一种拆分适用于所有 $`i`$。**

- $`p`$ 不随 $`w`$ 改变；反证时通常不知道它的具体数值。
- 拆分可以随 $`w`$ 改变，但不能每换一个 $`i`$ 就重新拆分。
- 引理不要求每一种合法拆分都能泵；它只保证至少存在一种。

## 2. 为什么正则语言一定满足：DFA 与鸽巢原理

来源：原稿第 6 页证明；以下补全状态下标与边界。

因为 $`L`$ 正则，存在识别它的 DFA $`M=(Q,\Sigma,\delta,q_0,F)`$。取 $`p=\lvert Q\rvert`$，不要求这个 DFA 最小，也不要求 $`p`$ 是最小泵长度。

任取 $`w=a_1a_2\cdots a_n\in L`$，其中 $`n\ge p`$。令 $`q_j`$ 表示读完前 $`j`$ 个符号后的状态，包含尚未读入符号时的初态 $`q_0`$。

观察 $`q_0,q_1,\ldots,q_p`$：这是 **$`p+1`$ 次状态访问**，但 DFA 只有 $`p`$ 个不同状态。由鸽巢原理，存在：

```math
0\le r<s\le p,\qquad q_r=q_s.
```

据此定义三个连续片段：

```math
x=a_1\cdots a_r,\qquad
y=a_{r+1}\cdots a_s,\qquad
z=a_{s+1}\cdots a_n.
```

当 $`r=0`$ 时，$`x=\epsilon`$；当 $`s=n`$ 时，$`z=\epsilon`$。检查三个条件：

| 条件 | 为什么成立 |
| --- | --- |
| $`\lvert y\rvert\ge1`$ | $`\lvert y\rvert=s-r>0`$，两次访问的位置不同 |
| $`\lvert xy\rvert\le p`$ | $`\lvert xy\rvert=s\le p`$，重复发生在前 $`p`$ 次转移内 |
| 对所有 $`i\ge0`$，$`xy^iz\in L`$ | 读 $`x`$ 到达 $`q_r`$；读 $`y`$ 回到 $`q_r`$；再读 $`z`$ 仍到原接受状态 |

$`y`$ 对应的是一段回到同一状态的非空路径，未必是一条自环边。重复走这段路径任意次，或者一次都不走，都不改变开始读取 $`z`$ 时的状态，所以仍接受。

**计数易错点：** 长度恰好为 $`p`$ 已经足够，因为要把初态也算进 $`p+1`$ 次访问；不需要强行要求 $`\lvert w\rvert>p`$。

## 3. 怎样用它证明一个语言非正则

泵引理给出正则性的**必要条件，不是充分条件**：违反泵性质可以推出非正则；满足泵性质本身不能推出正则。这一区分可核对 [Columbia 自动机课程的泵引理讲义](https://www.cs.columbia.edu/~aho/cs3261/Lectures/L5-Properties_of_Regular_Languages_I.html)。

反证法的关键是：假设语言正则以后，引理保证存在一种“好拆分”。要击破这个保证，必须让选定字符串的**所有合法拆分**都失败。

| 顺序 | 需要做什么 | 可以依赖什么 |
| --- | --- | --- |
| 1 | 假设 $`L`$ 正则，设其泵长度为 $`p\ge1`$ | 不知道 $`p`$ 的具体值 |
| 2 | 选择 $`w\in L`$ 且 $`\lvert w\rvert\ge p`$ | $`w`$ 可以依赖 $`p`$ |
| 3 | 任取满足 $`w=xyz`$、$`\lvert xy\rvert\le p`$、$`\lvert y\rvert\ge1`$ 的拆分 | 根据约束推导 $`y`$ 的形状，不能只挑自己喜欢的拆分 |
| 4 | 找一个 $`i\ge0`$，使 $`xy^iz\notin L`$ | $`i`$ 可以依赖该拆分；若所有拆分统一取 0 或 2，更简洁 |
| 5 | 得出没有任何拆分满足引理，产生矛盾 | 否定的是最初“$`L`$ 正则”的假设 |

这种反证对应的量词方向是：

```math
\begin{aligned}
&\forall p\in\mathbb Z_{\ge1}\ \exists w\in L:\quad \lvert w\rvert\ge p\ \land\\
&\quad \Bigl[\forall x,y,z\in\Sigma^*:\quad
\bigl(w=xyz\land \lvert xy\rvert\le p\land \lvert y\rvert\ge1\bigr)\\
&\qquad \Longrightarrow\ \exists i\in\mathbb Z_{\ge0}:\ xy^iz\notin L\Bigr].
\end{aligned}
```

上述 $`p,i`$ 均取整数。这是足以证明非正则的一种条件，不是所有非正则语言都必须能用这种方式证明。

## 4. 原稿例题：等量的 0 后面接等量的 1

证明语言 $`L=\{0^n1^n:n\ge0\}`$ 非正则。

**第一步：假设正则。** 设 $`p\ge1`$ 是泵长度，选择：

```math
w=0^p1^p\in L,\qquad \lvert w\rvert=2p\ge p.
```

**第二步：分析任意合法拆分。** 任取 $`w=xyz`$，满足 $`\lvert xy\rvert\le p`$、$`\lvert y\rvert\ge1`$。因为 $`w`$ 的前 $`p`$ 个符号全是 0，$`y`$ 必须完全落在这段 0 内。因此存在整数 $`k`$，使：

```math
y=0^k,\qquad 1\le k\le p.
```

注意这里**没有自行规定 $`y=0`$**，而是用 $`k`$ 覆盖所有允许的非空 0 串；$`x`$ 从哪里结束不影响下面的计数。

**第三步：统一取 $`i=0`$。** 删除 $`y`$ 后：

```math
xy^0z=xz=0^{p-k}1^p.
```

因为 $`k\ge1`$，0 的个数 $`p-k`$ 小于 1 的个数 $`p`$，故 $`xz\notin L`$。即使 $`k=p`$，结果是 $`1^p`$，仍不属于 $`L`$。

这对每一种合法拆分都成立，与泵引理要求“存在一种拆分对所有 $`i\ge0`$ 都留在 $`L`$ 中”矛盾。因此 **$`L`$ 非正则**。

**原稿推理补全：** $`y`$ 只含 0 来自 $`\lvert xy\rvert\le p`$；$`y`$ 至少含一个 0 来自 $`\lvert y\rvert>0`$。两个条件要一起使用，不能仅由“泵后仍在语言内”推出 $`y`$ 的形状。

## 5. 补充练习：长度为完全平方数的 0 串

本节为自编补充解析，用同一个证明模板练习“选择相邻平方数之间的长度”。证明 $`S=\{0^{n^2}:n\ge0\}`$ 非正则。

**解：** 假设 $`S`$ 正则，设泵长度为 $`p\ge1`$。取 $`w=0^{p^2}`$，则 $`w\in S`$ 且 $`\lvert w\rvert=p^2\ge p`$。

对任意合法拆分 $`w=xyz`$，令 $`k=\lvert y\rvert`$。由非空性和前缀长度限制，$`1\le k\le p`$。取 $`i=2`$，得到：

```math
xy^2z=0^{p^2+k},\qquad
p^2<p^2+k\le p^2+p<(p+1)^2.
```

长度严格介于相邻的完全平方数 $`p^2`$ 与 $`(p+1)^2`$ 之间，因而不是完全平方数，故 $`xy^2z\notin S`$。所有合法拆分均失败，矛盾，所以 $`S`$ 非正则。

不能只说“增加了几个 0，所以不是平方数”；必须证明增加量小于到下一个平方数的间隔。这里正是 $`k\le p<2p+1`$ 保证了这一点。

## 6. 自测与答案

1. **可以令 $`p=100`$，只证明长度足够大的串不能泵吗？** 不可以。反证要处理假设给出的任意可能泵长度，不能擅自固定一个方便的值。
2. **$`x`$ 和 $`z`$ 必须非空吗？** 不必；只有 $`y`$ 必须非空。
3. **取 $`i=0`$ 是否违反泵引理？** 不违反。它表示删除 $`y`$，是常用的反证选择。
4. **找到一个失败的拆分就足够了吗？** 不够。引理允许其他拆分成功；必须覆盖所选字符串的所有合法拆分。
5. **找到了若干字符串的成功拆分，能证明语言正则吗？** 不能。既未覆盖所有长串，泵性质本身也只是必要条件。
6. **有限语言没有任意长串，是否与泵引理矛盾？** 不矛盾。取 $`p`$ 大于其中所有字符串的长度，条件中就没有需要检查的长串；空语言也同理。
7. **DFA 的重复状态一定相邻吗？** 不一定；$`y`$ 可以对应多条转移组成的回路。
8. **$`\{0^{2n}:n\ge0\}`$ 也因为长度受限制而非正则吗？** 不是。它由正则表达式 $`(00)^*`$ 描述；不能把平方长度的证明照搬到偶数长度。

写完证明后检查四点：**字符串确实在语言内、长度达到 $`p`$、覆盖所有合法拆分、泵后离开语言的理由明确。**
