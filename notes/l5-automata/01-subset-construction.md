# L5 补充练习：ε 闭包与子集构造

> 对应材料：`L5_0_1793243778225.pdf` 第 1-2 页，页码采用 PDF 阅读器页序。下面的四状态例题为补充自编，用于练习原稿的 ε 闭包与子集构造；不是对手写图的转录。

DFA/NFA 的定义见 [Week 4 笔记](../../理论计算机科学导引_Week4_整理笔记.md)；完整的等价证明、连接和星构造见 [Week 5 笔记](../../理论计算机科学导引_Week5_整理笔记.md)。本篇沿用周记的固定字母表和转移关系记号，集中练习“初始闭包、读字符后的闭包、空集陷阱”三个步骤。

## 1. 做题前的三个公式

对于允许空转移的 NFA $`N=(K,s,F,\Delta)`$，$`\Delta(q,a)`$ 表示从 q 沿一条 a 边可到达的状态集合；$`E(S)`$ 表示从 S 沿零条或多条 ε 边可到达的状态集合。单个状态简写为 $`E(q)=E(\{q\})`$。

```math
S_0=E(\{s\}),\qquad
\delta_D(S,a)=E\left(\bigcup_{q\in E(S)}\Delta(q,a)\right).
```

可达子集已经满足 $`E(S)=S`$，所以逐行填写转移表时，内层 E(S) 可以简写为 S。保留内层闭包的公式也适用于任意尚未闭合的状态集合。记 $`K_D`$ 为从初始子集可达的所有子集组成的 DFA 状态集合，则：

```math
F_D=\{S\in K_D:S\cap F\ne\varnothing\}.
```

子集中**至少有一个原接受状态**就标为接受。空集如果可达，也要列入完整转移表；它对所有符号都回到自己，不是接受状态。它表示所有分支失败，与空串不同。

## 2. 四状态 ε-NFA 的完整转换

取 $`\Sigma=\{0,1\}`$、$`K=\{s,p,q,f\}`$，初态为 s，接受集合为 $`\{f\}`$。转移表中空集表示没有这类边：

| 状态 | 输入 0 | 输入 1 | ε 转移 |
| --- | --- | --- | --- |
| s（初态） | $`\varnothing`$ | $`\varnothing`$ | $`\{p\}`$ |
| p | $`\{p,q\}`$ | $`\varnothing`$ | $`\varnothing`$ |
| q | $`\varnothing`$ | $`\{f\}`$ | $`\{f\}`$ |
| f（接受） | $`\varnothing`$ | $`\varnothing`$ | $`\varnothing`$ |

首先求单状态闭包：$`E(s)=\{s,p\}`$、$`E(p)=\{p\}`$、$`E(q)=\{q,f\}`$、$`E(f)=\{f\}`$。

给可达子集起短名，得到完整 DFA：

| 名称 | 对应子集 | 输入 0 | 输入 1 | 是否接受 |
| --- | --- | --- | --- | --- |
| A（初态） | $`\{s,p\}`$ | B | D | 否 |
| B | $`\{p,q,f\}`$ | B | C | 是 |
| C | $`\{f\}`$ | D | D | 是 |
| D | $`\varnothing`$ | D | D | 否 |

例如 A 读取 0，s 没有后继，p 的后继是 p、q；再沿 q 的 ε 边加入 f，所以：

```math
\delta_D(A,0)=E(\varnothing\cup\{p,q\})=\{p,q,f\}=B.
```

B 读取 1，只有 q 能转到 f，因此到 C；B 读取 0，由 p 重新产生 p、q，再闭包到 f，因此仍到 B。

四个子集都可达：A 由 ε 到达，B 由 `0` 到达，C 由 `01` 到达，D 由 `1` 到达。虽然 $`2^4=16`$，这里只生成了 4 个可达状态。

| 输入 | DFA 路径 | 结果 |
| --- | --- | --- |
| ε | A | 拒绝 |
| `0` | A → B | 接受 |
| `001` | A → B → B → C | 接受 |
| `010` | A → B → C → D | 拒绝 |
| `1` | A → D | 拒绝 |

此机器的语言是 $`\{0^k:k\ge1\}\cup\{0^k1:k\ge1\}`$：至少一个 0，后面可有一个 1。从 B 读 `1` 到 C，仍接受；若随后从 C 读 `0`，则到 D 并拒绝。这说明必须读完整个输入后才作最终判定。

## 3. 自测与答案

1. 初态 s 没有读入任何符号，为什么 DFA 初态还要包含 p？**因为 s 可以沿 ε 边到 p，不消耗输入。**
2. 从 A 读 0 后为什么要加入 f？**先到达 p、q，再沿 q 的 ε 边到 f，必须求字符转移后的闭包。**
3. `0001` 和 `011` 是否接受？**前者最终到 C，接受；后者最终到 D，拒绝。**
4. B 读 0 和 C 读 0 的结果相同吗？**不同：B 读 0 仍在 B，C 读 0 到 D。**
5. 为什么不能把 D 从完整 DFA 表中删掉？**输入 `1` 已能到达 D；删去会留下缺失转移。**
6. 四个原状态是否一定生成 16 个 DFA 状态？**不是，16 是幂集上界；这里只生成 4 个可达子集，且子集构造本身不是最小化。**
